## 2. Локальные ссылки на чаты и автодобавление

### 2.1 API для добавления чата в список загрузок

**Файл:** [web/app.py](web/app.py)

**Новый endpoint:**

```
POST /api/chats/add
Body: { "chat_id": int, "title": string (optional) }
Response: { "added": bool, "message": string }
```

- Загрузить config через ConfigManager.
- Вызвать `add_chat_to_download_list(chat_id, title)`.
- Сохранить config.

### 2.2 Логика на фронте

В `parseTelegramLinks` / `formatMessageText`:

- При клике на t.me-ссылку, если `matchedChat` есть — `onOpenChat` (уже есть).
- Если `matchedChat` нет — вызов `POST /api/chats/add` с chat_id из ссылки, затем:
  - Показать toast: «Чат добавлен в список загрузок. После загрузки ссылка будет работать.»
  - Открыть внешнюю ссылку (t.me) или оставить внешнюю ссылку кликабельной.
- Для username-ссылок (t.me/username) маппинга chat_id нет — остаются внешними, при желании можно добавить чат по username через Telegram API (позже).

## 3. Фото и видео — просмотр, а не скачивание

### 3.1 Backend

**Файл:** [web/app.py](web/app.py), `get_message_file`.

- Определять MIME по расширению или media_type (photo → image/*, video → video/*).
- Для image/* и video/* устанавливать `Content-Disposition: inline`.
- Использовать `Response` или `FileResponse` с кастомными headers:
  ```python
  # Для фото/видео — inline, иначе attachment
  is_inline = media_type.startswith("image/") or media_type.startswith("video/")
  disposition = "inline" if is_inline else "attachment"
  headers = {"Content-Disposition": f'{disposition}; filename="{filename}"'}
  return FileResponse(path, media_type=..., headers=headers)
  ```
- Получать `media_type` из CH (по chat_id, message_id) или из расширения файла.

### 3.2 Frontend

- Фото: сейчас `<a href={fileUrl} target="_blank"><img src={fileUrl}/></a>`. При `inline` браузер будет показывать изображение во вкладке.
- Опционально: модальное окно (lightbox) для увеличенного просмотра по клику — улучшает UX.
- Видео: уже `<video src={fileUrl} controls>`, просмотр inline. Убедиться, что при переходе по ссылке файла (например, правый клик → «Открыть в новой вкладке») используется `inline`.

## 4. Хэштеги: локальный поиск по тегу

**Идея:** хэштеги в сообщениях (#tag) кликабельны; по клику отображаются только сообщения, содержащие этот тег.

**Реализация:**

- В `formatMessageText` хэштеги (MessageEntityHashtag) рендерить как кликабельные `<button>` или `<a href="#">` с классом (например `hashtag`).
- При клике вызывать `onFilterByHashtag(tag)` → устанавливать `searchQuery = tag` (например `"#python"`).
- Текущий поиск уже фильтрует `filteredItems` по `searchQuery` (поиск по тексту). Достаточно установить `searchQuery` в значение тега — фильтрация сработает автоматически.
- Показать подсказку «Показаны сообщения с тегом #tag» и кнопку «Сбросить фильтр».

**Frontend:**

  - Ссылка на профиль (t.me/…) — кликабельная, открывается во внешней вкладке.

## 6. Увеличение окна и кнопки навигации

### 4.1 Размер окна

**Файл:** [web/ui/src/App.jsx](web/ui/src/App.jsx)

- Сейчас: `max-h-[90vh]`, `minHeight: 360` у Virtuoso.
- Увеличить до `max-h-[95vh]` или убрать ограничение, задать большую minHeight (например 500–600px).
- Контейнер ChatViewer: `max-w-2xl` — при необходимости расширить до `max-w-4xl` для удобства чтения.

### 4.2 Кнопки навигации

Добавить под панелью поиска или над Virtuoso компактную панель:

- В начало (первое сообщение)
- Назад (на PAGE_SIZE вверх)
- Вперёд (на PAGE_SIZE вниз)
- В конец (последнее сообщение)

**Реализация:**

- Virtuoso: `scrollToIndex(0)` — в начало, `scrollToIndex(data.length - 1)` — в конец.
- «Назад» / «Вперёд» — скролл на PAGE_SIZE пунктов через `scrollToIndex` с учётом текущей видимой позиции (Virtuoso не даёт «текущий индекс», можно хранить приближённое значение через `rangeChanged` или использовать фиксированные шаги).
- Альтернатива: кнопки «В начало» / «В конец» + ползунок или номера страниц (если total известен).

Упрощённый вариант: только «В начало» и «В конец» — реализуются через `virtuosoRef.current.scrollToIndex({ index: 0 })` и `scrollToIndex({ index: filteredItems.length - 1 })`.
