# План: Улучшение веб-интерфейса чатов

## Задачи

### 1. Изменение строк поиска в ChatsView

**Файл:** `web/ui/src/App.jsx`

- Переместить строку поиска сообщений на один уровень со строкой поиска чатов (в `ChatsView`)
- Строка поиска сообщений будет искать во всех чатах, а не только в текущем
- При вводе в строку поиска сообщений показывать результаты из всех чатов

**Изменения:**

- Добавить состояние `globalMessageSearchQuery` в `ChatsView`
- Добавить строку поиска сообщений рядом с поиском чатов (строки на одном уровне)
- При наличии `globalMessageSearchQuery` показывать результаты поиска вместо списка чатов или в отдельной панели
- **При клике на найденное сообщение:** открывать чат этого сообщения (`onOpenChat` с `chat_id` и `initialMessageId` из результата поиска)

### 2. API для поиска сообщений во всех чатах

**Файлы:** `web/app.py`, `utils/clickhouse_db.py`

**Новый endpoint:** `GET /api/messages/search?q=...&offset=...&limit=...`

- Параметры: `q` (поисковый запрос), `offset`, `limit`
- Поиск по тексту сообщений во всех чатах
- Возвращает список сообщений с информацией о чате

**Метод в ClickHouse:** `search_messages_all_chats(q, offset, limit)`

- Нечеткий поиск с использованием встроенных функций ClickHouse:
  - Разбить запрос на слова (split по пробелам)
  - Для каждого слова использовать `multiSearchAny` или `positionCaseInsensitive`
  - Альтернативно: использовать `ngramDistance` или `levenshteinDistance` для нечеткого совпадения
  - Комбинировать условия через `OR` для поиска по любому слову
- Группировка по `chat_id, message_id` для дедупликации
- Возвращает сообщения с `chat_id`, `chat_title`, `message_id` для навигации

## Дополнительные требования

### Нечеткий поиск в ClickHouse

Использовать встроенные функции ClickHouse для нечеткого поиска:

1. **Вариант 1: multiSearchAny** (рекомендуется)

```sql
   WHERE multiSearchAny(text, ['word1', 'word2', 'word3'])


```

1. **Вариант 2: Разбиение на слова с OR**

```sql
   WHERE (positionCaseInsensitive(text, 'word1') > 0
      OR positionCaseInsensitive(text, 'word2') > 0)


```

1. **Вариант 3: ngramDistance** (для опечаток)

```sql
   WHERE ngramDistance(text, %(q)s) < 3


```

Рекомендуется использовать комбинацию: разбить запрос на слова и искать каждое слово через `multiSearchAny` или `positionCaseInsensitive`.

### Навигация по результатам поиска

- При клике на найденное сообщение вызывать `onOpenChat({ chat_id, initialMessageId })`
- Это откроет чат и прокрутит к нужному сообщению

### Расширение окна сообщений

- Увеличить `minHeight` в `Virtuoso` с 520px до 700-800px для embedded режима
- Для модального окна увеличить `max-h-[95vh]` или использовать `max-h-[98vh]`
