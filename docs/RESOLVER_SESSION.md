# Сессия резолвера веб-дашборда

Резолвер (username → chat_id, chat_id → title, фото профиля, полный профиль чата) использует отдельную сессию Telegram **`media_downloader_resolver`**, чтобы не конфликтовать с основной сессией загрузчика.

Резолвер **не запрашивает** телефон и код в консоли: если сессия не авторизована, в логах и в API возвращается ошибка с этой инструкцией.

## Однократная авторизация сессии резолвера

1. Остановите веб-сервер (и при необходимости загрузчик).
2. В корне проекта выполните в консоли:

```bash
python -c "
from telethon import TelegramClient
from utils.config import ConfigManager
c = ConfigManager().load()
client = TelegramClient('media_downloader_resolver', c['api_id'], c['api_hash'])
client.start()
print('Готово')
"
```

3. Введите телефон и код, когда их запросят.
4. Запустите веб снова — резолвер будет работать без запросов в консоль.

После этого сессия сохраняется в файле (например, `media_downloader_resolver.session`) и повторный ввод не нужен.
