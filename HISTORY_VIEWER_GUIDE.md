# 📱 Просмотр истории Telegram чатов в браузере

## 🎯 Полноценный аналог Telegram Web

История чатов сохраняется в красивом веб-интерфейсе, который является полным аналогом Telegram Web. Все файлы доступны напрямую через абсолютные пути `file://` - идеально для USB дисков в Linux!

## 🚀 Быстрый старт

### 1. Включить сохранение истории

В `config.yaml` установите:

```yaml
download_settings:
  base_directory: /media/disk/Telegram
  download_message_history: true  # Включить сохранение
  history_directory: history      # Папка для истории
  history_format: html            # Формат: html, json или txt
```

### 2. Запустить загрузку

```bash
python media_downloader.py
```

### 3. Открыть в браузере

После загрузки откройте файл:

```
/media/disk/Telegram/history/index.html
```

или напрямую через браузер:

```
file:///media/disk/Telegram/history/index.html
```

## ✨ Возможности веб-интерфейса

### 🎨 Дизайн как в Telegram Web

- **Темная и светлая темы** - переключение одним кликом (сохраняется в браузере)
- **Пузыри сообщений** - как в оригинальном Telegram
- **Плавные анимации** - появление сообщений, наведение мыши
- **Современный UI** - минималистичный дизайн в стиле Telegram

### Главная страница (index.html)

- 📋 Список всех чатов с аватарами (первая буква названия)
- 📊 Количество сообщений и дата последнего сообщения
- 🌓 Переключатель темы (тёмная/светлая)
- 📱 Полностью адаптивный дизайн

### Страница чата

#### 🖼️ Медиа-контент:
- **Фото** - встроенные превью с увеличением
- **Видео** - встроенный плеер с контролами и длительностью
- **Документы** - красивые карточки с иконками и размером файла
- **Аудио и голосовые** - с иконками и длительностью

#### 📎 Файлы:
- **Абсолютные пути** с протоколом `file://` - работают на USB дисках в Linux!
- **Прямое открытие** - клик на изображение/видео открывает файл
- **Обработка ошибок** - если файл не найден, показывается сообщение

#### 🔍 Функционал:
- **Поиск в реальном времени** по всем сообщениям
- **Кликабельные ссылки** в тексте сообщений
- **Просмотры и переадресации** внизу сообщения
- **Ответы на сообщения** с указанием ID
- **Редактирования** помечены меткой "edited"
- **Автопрокрутка** вниз при открытии (как в Telegram)

## 🔧 Продвинутое использование

### Поиск по всем чатам

HTML интерфейс поддерживает поиск на странице каждого чата. Используйте поле поиска вверху страницы.

### Экспорт данных

Рядом с каждым HTML файлом есть соответствующий JSONL файл с теми же данными в JSON формате для программной обработки.

### Резервное копирование

Просто скопируйте папку `history/` для создания резервной копии всей истории сообщений.

### Перенос медиа в другую папку

Если вы перенесли скачанные файлы (photo, video, document и т.д.) в другую папку или на другой диск (например, NAS), ссылки в истории и HTML можно перевести на новый путь:

1. **Для новых загрузок** — в `config.yaml` задайте `media_links_base` (папка, куда будут указывать ссылки):

   ```yaml
   download_settings:
     base_directory: /media/disk/Telegram   # куда реально качаем
     media_links_base: /mnt/nas/Telegram    # куда указывают ссылки в истории
   ```

2. **Для уже сохранённой истории** — запустите скрипт перезаписи (после того как перенесли файлы в новую папку и прописали `media_links_base` в конфиге):

   ```bash
   python rewrite_media_links.py --regenerate-html
   ```

   Опция `--dry-run` покажет, что будет заменено, без записи. После перезаписи ссылки в `chat_*.jsonl`, ClickHouse и в `chat_*.html` будут указывать на `media_links_base`.

## 🌐 Открытие в веб-сервере

## ⚠️ Важные замечания

### ✅ Решение проблем с путями к файлам

Теперь используются **абсолютные пути** с протоколом `file://`, что решает проблемы с:
- USB дисками в Linux
- Различными точками монтирования
- Относительными путями

Формат пути: `file:///media/disk/Telegram/photo/image.jpg`

### 📝 Прочее

1. **Размер файлов**: HTML файлы могут быть большими для чатов с тысячами сообщений
2. **Превью медиа**: Изображения и видео загружаются "лениво" (lazy loading)
3. **Обновление**: При каждой загрузке HTML файлы полностью перегенерируются
4. **Безопасность**: История содержит все ваши сообщения - храните файлы в безопасном месте
5. **Браузер**: Для открытия файлов по `file://` может потребоваться разрешение в настройках браузера

## 🏗️ Техническая архитектура

### Как работает система истории

История использует **двухуровневую архитектуру**:

1. **JSONL (Источник истины)** - быстрая запись, накопление данных
2. **HTML (Презентация)** - красивое отображение

#### Поток данных

```
Загрузка → JSONL (append) → HTML (регенерация)
```

Подробнее см. [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

### Частота обновления

HTML обновляется после каждого пакета сообщений:

```yaml
download_settings:
  pagination_limit: 100  # Обновление каждые 100 сообщений
```

**Рекомендации:**
- `50-100` - для малых чатов (частые обновления)
- `100-200` - для средних чатов (баланс)
- `200-500` - для больших чатов (производительность)

### Изоляция данных между чатами

Каждый чат использует уникальный идентификатор `(chat_id, message_id)` для привязки файлов к сообщениям. Это предотвращает коллизии при загрузке нескольких чатов.

### Управление памятью

После завершения загрузки каждого чата его данные удаляются из оперативной памяти. Это позволяет загружать неограниченное количество чатов без переполнения памяти.

**Экономия:** до 93% RAM при загрузке нескольких чатов
